# 🚀 «Архив кода» — API для навигации по кодовой базе.

Профессиональный REST API сервис на базе **FastAPI**, разработанный для автоматического анализа (индексации) структуры исходного кода Python-проектов и предоставления удобного интерфейса для поиска и навигации по коду.

Проект разработан в рамках чемпионата по программированию с соблюдением всех требований ТЗ, принципов чистой архитектуры, паттернов проектирования и контейнеризации.

---
# 🚀 Ключевые возможности и выполненные требования

- **Умная индексация на базе AST (Abstract Syntax Tree):** Скрипт-индексатор анализирует реальное абстрактное синтаксическое дерево Python-файлов, извлекая классы, функции, их точные номера строк (начала и конца), а также встроенные строки документации (`docstring`).
- **Регистронезависимый глобальный поиск:** Полнотекстовый гибкий поиск по всей кодовой базе через SQL-операторы с полной поддержкой поиска как по имени сущности, так и по содержимому `docstring`.
- **Защита данных и валидация (Input Validation):** Сервер защищен от пустых поисковых запросов и запросов, состоящих только из пробелов — в таких случаях возвращается корректный пустой список `[]` без лишней нагрузки на СУБД.
- **Архитектура БД со связями (1:N):** Локальная реляционная СУБД SQLite хранит структурированные сущности с внешними ключами, связывающими функции/классы с конкретными файлами в индексе.
- **Идемпотентность переиндексации:** При повторном запуске индексатора старые данные автоматически очищаются, что предотвращает появление дубликатов в базе данных и гарантирует актуальность среза кода.
- **Полная контейнеризация (Docker):** Сервер готов к развертыванию одной командой, инкапсулируя внутри себя операционную систему Linux и все необходимые Python-зависимости, полностью решая проблему совместимости.

# 🛠 Описание Эндпоинтов


```
 GET /api/files  
 ```
 ### Назначение: 
 Получение списка всех успешно проиндексированных файлов в системе.

 ### Формат ответа:
  JSON-список строк (имён файлов).

---
```
GET /api/search
```
### Назначение:
 Глобальный регистронезависимый поиск классов и функций по названию или тексту из docstring. Добавлена пагинация (?limit=, ?offset=)

### Валидация:
 При передаче пустого значения или пробелов мгновенно возвращает [].

 ---
```
GET /api/files/{filename}/structure
```

### Назначение:
 Извлечение детальной структуры конкретного файла (список его функций и классов с номерами строк).

### Отказоустойчивость:
Если файл не найден в базе, возвращает пустой список [].

```
GET /api/stats
```
### Назначение:
Поиск сводной статистики (количество файлов, функций, классов)

# 1. 📦 Запуск через Docker

1. Сборка Docker-образа:

```
docker build -t api-navigation 
```
2. Запуск Docker-контейнера:
```
docker run -p 8080:8080 api-navigation
```

---

# 2. 💻 Запуск локально

1. Подготовка базы данных (Индексация кода):
```
python3 code_parser/indexer.py
```
2. Установка зависимостей проекта:
```
python3 -m pip install -r requirements.txt --break-system-packages
```

3. Запуск веб-сервера FastAPI:
```
python3 -m uvicorn app.main:app --reload
```
